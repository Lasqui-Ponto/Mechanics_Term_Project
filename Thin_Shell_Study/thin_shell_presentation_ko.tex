\begin{frame}{1. 전하 정확도와 힘 정확도는 별도의 검증 대상이다}
 \begin{columns}[T,onlytextwidth]
 \begin{column}{.48\textwidth}
  \begin{block}{점근적인 원천의 기술}
   \[u=1-sQ\frac{e^{-\mu(x-1)}}x\]
   하나의 전하가 먼 거리의 장을 요약한다.
  \end{block}
  \begin{itemize}
   \item 얇은 껍질 모형이 $Q$를 잘 예측하는가?
   \item 어떤 보정이 성능 향상에 기여하는가?
  \end{itemize}
 \end{column}
 \begin{column}{.48\textwidth}
  \begin{block}{고전역학의 관측량}
   \[a_5=-\frac{\beta}{M_{\rm Pl}}\nabla\phi\]
   가까운 탐침은 국소 기울기에 반응한다.
  \end{block}
  \begin{itemize}
   \item 어느 거리부터 꼬리 공식이 정확한가?
   \item 근사가 임계값 판정을 바꾸는가?
  \end{itemize}
 \end{column}
 \end{columns}
 \vfill\centering\small
 힘의 수치적 기준값은 \textbf{비선형 장에서 직접 계산한 기울기}이다.
\end{frame}

\begin{frame}{2. 구대칭 모형과 얇은 껍질 매개변수}
 \begin{columns}[T,onlytextwidth]
 \begin{column}{.53\textwidth}
  \[V=\frac{\Lambda^5}{\phi},\quad x=\frac rR,\quad u=\frac\phi{\phi_\infty}\]
  \begin{block}{$n=1$, 약한 등각 결합 극한}
   \[u''+\frac2x u'=\frac{\mu^2}{2}(\widetilde\rho-u^{-2})\]
   \[u'(0)=0,\qquad u(\infty)=1\]
  \end{block}
  \[\delta=\frac{\rho_c}{\rho_\infty},\quad \mu=m_\infty R,\quad m_cR=\mu\delta^{3/4}\]
 \end{column}
 \begin{column}{.43\textwidth}
  \[\eps=\frac{2(1-\delta^{-1/2})}{\mu^2\delta}\]
  \small 퍼텐셜 차이로 정의한 매개변수이며, 실제 기하학적 두께와 정확히 같지 않다.
  \begin{block}{유한한 내부 질량의 보정}
   \[\eps\simeq\frac{\Delta R}{R}+\frac1{m_cR}\]
   \scriptsize 관련된 큰 질량의 점근 영역:\\
   Tamaki--Tsujikawa (2008), 식 (48).
  \end{block}
 \end{column}
 \end{columns}
 \vfill\scriptsize\color{graytext}
 완전한 지수 결합에는 $D=\phi_\infty/M_c$도 포함된다. 주사에서는 $D\to0$을 명시적으로 취한다.
\end{frame}

\begin{frame}{3. 유한 범위 모형과 보정 요소를 분리하는 대조군}
 \small
 \[\qlr=\min(3\eps,1),\qquad \qsurf=\qlr,\quad \qctr=e^{-\mu}\qlr\]
 \[q=\sqrt{\max(1-2\eps,0)},\qquad \qms=1-q^3\]
 \begin{columns}[T,onlytextwidth]
 \begin{column}{.46\textwidth}
  \begin{block}{점원천 인자와 유한 부피}
   \[\qpv=e^{-\mu}(1-q^3)\]
   같은 중심부 반지름과 활성 부피를 가정한다.
  \end{block}
 \end{column}
 \begin{column}{.50\textwidth}
  \begin{block}{추가 구대칭 반지름 가중치}
   \[\qas=\frac{3e^{-\mu}}{\mu^3}[g(\mu)-g(\mu q)]\]
   \[g(z)=z\cosh z-\sinh z\]
  \end{block}
 \end{column}
 \end{columns}
 \vfill\scriptsize
 모든 계수는 같은 표면 기준 꼬리 정규화를 쓴다. 기준을 바꾸는 것만으로 물리는 달라지지 않는다.
 앞의 두 식은 서로 다른 진폭 가설이며, 중심부 반지름도 수치해에서 측정한 값이 아니다.
\end{frame}

\begin{frame}{4. 비선형 BVP와 직접 힘의 기준값}
 \begin{columns}[T,onlytextwidth]
 \begin{column}{.49\textwidth}
  \small
  \begin{itemize}
   \item 밀도 불연속의 정확한 처리: 내부·외부 영역 분리
   \item 중심 정칙성, 표면 정합, 외부 로빈 조건
   \item 전하로 스케일한 선형·로그 장 변수
   \item SciPy의 적응형 4차 콜로케이션
  \end{itemize}
  \begin{block}{수치 실험}
   \centering \StudyPoints 개 BVP, $x_{\max}=160$\\
   $10^2\leq\delta\leq10^5$, $10^{-3}\leq\mu\leq0.3$\\
   $1.02R$부터 $20R$까지 \StudyRadiusSamples 개 거리의 직접 힘
  \end{block}
 \end{column}
 \begin{column}{.47\textwidth}
  \begin{block}{비선형 장의 국소 힘}
   \[\ad(x)=\frac{2\beta^2Q_t}{s}x^2u'_{\rm num}(x)\]
   \[s=\frac{\mu^2\delta}{6}\]
  \end{block}
  \small 꼬리 예측은 별도로 계산한다.
  \[\at=2\beta^2Q_tQ(1+\mu x)e^{-\mu(x-1)}.\]
  기준은 원천 물체 총질량의 뉴턴 가속도이다.
 \end{column}
 \end{columns}
\end{frame}

\begin{frame}{10. 직접 힘을 기준으로 수정한 임계값 지도}
 \centering\includegraphics[width=.97\textwidth]{detectability_map.png}
 \vspace{.05cm}
 \small
 $\beta=Q_t=1$, $r=1.5R$, 예시 임계값 $\alpha_\star=\StudyThreshold$.\\[3pt]
 수치 전하의 꼬리 공식은 \StudyTailFlips 개 점에서 오판한다.
 표면·중심 모형의 오판은 각각 \StudySurfaceFlips 개·\StudyCenterFlips 개이다.\\[3pt]
 국소 힘비의 지도이며, 실제 장치의 크기와 잡음은 포함하지 않는다.
\end{frame}

\begin{frame}{11. 두 오차의 상쇄가 관측량의 정확도 순위를 바꾼다}
 \[\frac{\at(Q_j,x)}{\ad(x)}=
   \frac{Q_j}{\qnum}\frac{\at(\qnum,x)}{\ad(x)}\]
 \begin{columns}[T,onlytextwidth]
 \begin{column}{.47\textwidth}
  \begin{block}{두 오차는 곱해진다}
   전하의 과대평가는 꼬리 공식의 근거리 과소평가를 일부 상쇄할 수 있다.
   전하 정확도만으로 국소 힘의 정확도 순위를 정할 수 없다.
  \end{block}
  \small 활성 껍질의 10\% 목표 달성 비율:\\
  전하 \StudyASWithin\%, $1.5R$의 힘 \StudyASLocalWithin\%.
 \end{column}
 \begin{column}{.49\textwidth}
  \small
  \begin{itemize}
   \item 여러 힘비 임계값을 검사한다. 교차가 없는 경우도 정상적인 결과다.
   \item 거리 유효성은 $n=1$, $D\to0$의 이 구대칭 격자에 조건부로 성립한다.
   \item 실제 검출 가능성에는 기하, 변조, 탐침 반응과 잡음이 추가로 필요하다.
  \end{itemize}
 \end{column}
 \end{columns}
\end{frame}

\begin{frame}{12. 이 연구가 확인한 것}
 \begin{enumerate}
  \item 지정한 전하 모형을 비선형 BVP와 재현 가능하게 비교할 수 있다.
  \item 대조군은 반지름 가중치의 인과적 역할에 대한 주장을 제한한다.
  \item 직접 기울기를 기준으로 거리 의존적인 전파 오차를 확인한다.
  \item 수정된 힘은 $\alpha_\star=\StudyThreshold$에서 \StudyTailFlips 개 판정을 바꾼다.
 \end{enumerate}
